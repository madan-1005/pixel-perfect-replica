# Reel Studio — free, runs on your computer

No credits, no payment. Everything is free.

## 1. One-time setup
1. Install **Node.js** (nodejs.org) or **Bun** (bun.sh).
2. Install **Ollama** (ollama.com), then in a terminal run:
   `ollama pull llama3.2`
3. Get a free **Pexels** key at pexels.com/api (for stock video clips).

## 2. Run
```
npm install
npm run dev
```
Open **http://localhost:8080**, go to **Settings**, paste your Pexels key, click **Test Ollama**.

## What's free and where it runs
- Scripts: Ollama on your PC
- Voice (English): runs in your browser
- Transcription (many languages): runs in your browser
- Scene clips: free Pexels stock footage
- Music: upload your own (free tracks at pixabay.com/music)
- Projects and videos: saved in your browser on this computer

The first voice and transcription use downloads free models once (about 100–150 MB).
